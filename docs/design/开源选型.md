## 不建议用的

| 项目 | 原因 |
|---|---|
| Redis / BullMQ | pg-boss 够用，少一个要维护的服务 |
| MongoDB | 账本和多租户隔离依赖关系型约束和 RLS |
| 大型 UI 框架（Ant Design、MUI） | 手机端的老人尺寸规则和它们冲突，网页端现有样式已够 |
| Electron 做 POS | Capacitor 一套代码同时覆盖手机和收银平板 |
