# 第七部分：建造计划（4 阶段约 48 周）

## 三个贯穿全程的决定

| 决定 | 做法 | 原因 |
|---|---|---|
| 技术路线 | 一个后端 + PostgreSQL（行级安全）。手机和 POS 同一套跨平台 App，本地 SQLite 离线。网页一套。大屏是网页全屏模式 | 一套代码三种设备。触发器和 RLS 对应"库存只走账本"和"多租户隔离" |
| 第一阶段就做多租户和离线 | company_id、UUID、同步队列从第一天就有 | 后补等于重写 |
| 每阶段真店试点 | 第一阶段结束就有一家 A 模式小店跑真数据 | 老年员工能不能用只有真店能验证 |

## 第一阶段：地基（8 到 10 周）

目标：A 模式小店能 Excel 开店、打标签、收货、补货、查库存。库存只走账本。

| 范围 | 内容 |
|---|---|
| 数据库 | 第一、二、三、十、十一、十三组表。Movement 触发器、只插入约束、RLS、审计触发器 |
| 后端 | 登录、同步、主数据、库存移动、Excel 导入导出、用户角色权限、设备 |
| 手机 | 四个模板、C1 到 C8、收货、上架、补货、登记位置、查询。离线队列 |
| 网页 | G1 到 G5、G7、G10 库存报表、G11、G13、G14。超管 A1 到 A3 |
| A 模式模板 | 类别、A 到 F 加 S、三角色、最低量规则 |
| 不做 | 审批、Telegram、盘点、PO、POS、发票、大屏、机器人、工单 |

验收：老板一个 Excel 开店。库存员贴标签、收货、补货，老板网页看到每笔移动。关 Wi-Fi 收货恢复后同步。65 岁员工 30 分钟培训后独立收货补货。

## 第二阶段：控制（10 到 12 周）

目标：盘点、按单收货、每日订货建议、PO、Telegram 审批。B 模式仓库和调拨可用。工单最小版。

| 范围 | 内容 |
|---|---|
| 数据库 | 第四、五、六组。ApprovalRequest、Delegation、Ticket 基础 |
| 后端 | 盘点、采购建议定时、PO PDF Excel、收货对 PO、GRN、建议货位、调拨、统一审批、代理、Telegram 按钮和日报 |
| Telegram | 每日订货、单项审批、日报、收货摘要、代理通知。不做自由问答 |
| 手机 | K1 到 K7、W1 到 W12、S7 S8、M1 到 M6、O5 到 O7、C6 |
| 网页 | G6 货位绑定、G8、G9、B1 到 B5 |
| 工单最小版 | 盘点差异、收货差异、调拨差异、负库存自动开单；指派、评论、照片、关闭 |
| B 模式开通 | 多站点、容量、调拨、经理采购员、门槛 |

验收：小店早 8 点 Telegram 订货清单，老板批，PDF 到手，收货对 PO，差异开工单。盲盘一区，老板批差异。设代理，代理批一次，老板收晚报。B 模式第二试点完成仓库收货、上架、调拨、店收闭环。

## 第三阶段：钱（12 到 14 周）

目标：自有 POS、Pandal 对接、三种发票、MyInvois、月结。

| 范围 | 内容 |
|---|---|
| 数据库 | 第七、八、九组 |
| 自有 POS | P1 到 P12。多机、收据号、称重解析、电子秤串口、打印、钱箱、顾客侧屏、离线、挂单 |
| 开放 API | 第七组。Pandal 适配器两条路 |
| 应收 | 客户、记账、发票、收款、对账单、逾期 |
| 应付 | 录入、三方匹配、差异、付款、审批 |
| MyInvois | 沙盒、个人、企业、合并、取消、重试、二维码。沙盒过再生产 |
| 月结 | 检查清单、锁定 |
| 网页 | F1 到 F8、O8、B6 |
| 报表 | 销售多维、损耗、周转、库龄、应收账龄、应付到期 |

验收：小店自有 POS 卖一周，每笔扣库存，日结现金差上报表。电子发票二维码在 LHDN 门户可查。月底合并发票成功。B 模式 Pandal 销售 5 分钟内入库扣库存；供应商发票匹配差异处理付款，超门槛老板批。会计师确认合规。

## 第四阶段：顾客和智能（10 到 12 周）

目标：大屏、AI 自由问答、工单完整版、知识库闭环。

| 范围 | 内容 |
|---|---|
| 大屏 | D1 到 D8。地图、路线、缓存、长连接、叫员工。G6 顾客地图和通道 |
| 上架员 | S6 呼叫铃声。货架登记实时推送 |
| AI | /bot/ask 文字语音三语、意图分类、13 个固定查询、知识库向量、答不出开工单、主管回答存库。App 和 Telegram |
| 工单完整版 | 全部来源、期限表、超期提醒、设备心跳、大屏 10 分钟、关闭原因统计 |
| 知识库 | 系统 SOP 初始版每屏一条三语。A5 |
| 监控 | A6、A7 |
| 收尾 | 性能：5 台 POS 同时、100 人在线。安全：跨公司、大屏非 kiosk、收银员查成本 |

验收：大屏打"酱油"亮货架路线，上架员换货架大屏 2 秒更新。叫员工手机响。收银员语音问可乐位置得中文答案，问成本被拒。盘点员问 SOP 没有的问题，经理回答后第二人直接得答。
