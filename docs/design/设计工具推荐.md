# 除了 Figma 还能用什么（免费、给非设计师）

Figma 是给设计师画图的，对老板来说确实不顺手。你的需求是"打字 → 出屏幕 → 发给开发"，下面这些更合适。我们写好的提示词（`Figma提示词.md`、`Figma提示词-全功能.md`）在这些工具里**原样能用**。

## 推荐顺序

| 排名 | 工具 | 为什么 | 免费情况 | 给我的方式 |
|---|---|---|---|---|
| 1 | **Google Stitch** stitch.withgoogle.com | 谷歌出的，打一段字出 1–5 张连起来的屏幕，能一直追加修改，自带 HTML 导出。最接近你用过的 Muse | 免费（测试期），每月几百次生成 | 导出 HTML 发我，或复制到 Figma 后发链接 |
| 2 | **Pixso** pixso.cn | 中文界面，国内团队，有 AI 生成界面，出来的是可编辑图层 | 免费版够用，AI 每天有额度 | 分享链接或导出 PNG |
| 3 | **即时设计** js.design | 中文界面，Figma 的国产替代，免费，有 AI 功能 | 个人免费 | 分享链接 |
| 4 | **v0** v0.app（Vercel） | 打字直接出 React 代码，我可以直接拿来用，最省我的时间 | 有免费额度，但 2026 年起对新用户可能是一次性额度，用完要付费 | 复制代码或分享链接 |
| 5 | **Muse** muse.ai | 你已经用过，导出 HTML 我已经接进去过一次 | 有免费额度 | 导出 HTML |
| 6 | **Claude / ChatGPT 直接出 HTML** | 把提示词贴进去，让它"做成一个 HTML 页面"，浏览器打开就能看 | 免费版可用 | 把 HTML 文件发我 |

不推荐：Canva（只能做图不能做 App 流程）、Adobe XD（已停止更新）、Sketch（只有 Mac 且收费）。

## 我的建议：用 Google Stitch

理由三条：
1. 不用学。打字、看图、不满意再打一句，和聊天一样。
2. 一次出一个流程（最多 5 屏连起来），正好对应我们每个模块的"整流程"提示词。
3. 导出 HTML。我接 HTML 比接 Figma 文件快，样式和间距都在代码里，不用猜。

Stitch 的用法：
1. 打开 stitch.withgoogle.com，用 Google 账号登录。
2. 选 Mobile（手机）或 Web（电脑），把"设计系统"那段贴进去，再贴一个模块的"整流程"提示词。
3. 出来后，右边聊天框里追加修改，例如 "Make the buttons 80px tall" 或贴 `Figma提示词.md` 第 9 节的修改句。
4. 满意后点 Export → HTML（或 Copy to Figma）。HTML 文件发我。

已知缺点：超过 3 屏的流程有时风格会漂，所以**每次只做一个模块**，并且每个新对话都先贴设计系统那段。

## 如果你更想要中文界面：Pixso

1. 打开 pixso.cn，注册免费账号。
2. 新建文件 → 右上角 AI → "AI 生成界面"，贴提示词（可以贴中文，但英文结果更稳）。
3. 生成的是图层，可以直接拖动改字。
4. 分享 → 复制链接（任何人可查看）发我。

## 哪种输出我接得最快

| 你给我的 | 我接进 App 要多久 |
|---|---|
| HTML 文件（Stitch、Muse、Claude） | 半天到一天一个模块 |
| React 代码（v0） | 半天一个模块 |
| Figma / Pixso / 即时设计 链接 | 一天一个模块，我要自己量尺寸 |
| 截图 PNG | 一到两天，要猜间距和字号 |

## 这周怎么开始

1. 用 Stitch 贴"设计系统" + 模块 1 "共用"的整流程提示词，出登录、首页、查询、设置。
2. 看不顺眼就追加修改句，改到你满意。
3. Export HTML 发我。我接进去后，你在手机上看真实效果，再决定下一个模块。
