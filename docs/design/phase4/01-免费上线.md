# 免费让手机用上（两种方式）

## 方式一：电脑跑系统，Cloudflare 免费隧道给手机一个 https 网址（今天就能用）

适合：试用、培训、店里先跑。电脑开着系统就在；电脑关了就停。

1. 电脑按 README「Windows 上运行」把系统跑起来（两个窗口：`.\e2e\reset-and-seed.ps1` 和 `pnpm dev:app`）。
2. 下载 cloudflared（免费，不用注册）：https://github.com/cloudflare/cloudflared/releases/latest 里的 `cloudflared-windows-amd64.exe`，改名 `cloudflared.exe` 放到项目文件夹。
3. 再开一个 PowerShell：

```powershell
.\cloudflared.exe tunnel --url http://localhost:5173
```

4. 窗口里会出现一行 `https://xxxx-xxxx.trycloudflare.com`。手机浏览器开 `https://xxxx-xxxx.trycloudflare.com/m` 就是手机端，`/pos` 是收银，`/w` 是网页端。Chrome 菜单「添加到主屏幕」变成 App 图标。
5. 因为是 https，手机摄像头扫码可以用，离线也可以用。

限制：
- 网址每次重开隧道都会变（要固定网址需免费 Cloudflare 账号加一个域名，域名约 RM 40 一年）。
- Cloudflare 说明是测试用途，200 个并发连接，没有正常运行保证；顾客大屏的即时推送（SSE）在这种隧道下不通，大屏会退回每 10 秒刷新。
- 电脑休眠隧道就断，店里用要把电脑设成不休眠。

## 方式二：Oracle Cloud 永久免费服务器（正式用，不依赖你的电脑）

适合：多家店、手机随时随地用、收银机不在同一地方。

Oracle Cloud 的 Always Free 有一台 ARM 服务器（目前 4 核 24GB，有报道说 2026 年 8 月后减为 2 核 12GB，对我们够用），永久免费，但注册要信用卡验证（不扣费），而且热门区域经常没货要多试几次。

步骤：
1. 注册 https://cloud.oracle.com ，选 Singapore 或 Kuala Lumpur 区域。
2. 建 VM：Ampere A1，Ubuntu 24.04 aarch64，2 OCPU 12GB，开放 80 和 443 端口（安全列表加入站规则）。
3. 免费域名：https://www.duckdns.org 注册一个 `你的店.duckdns.org`，指向 VM 的公网 IP。
4. SSH 进 VM：

```bash
sudo apt update && sudo apt install -y docker.io docker-compose-v2 git
```

```bash
git clone -b claude/pensive-fermat-k3wys1 https://github.com/profunction/warehouse-important-.git && cd warehouse-important-
```

```bash
DOMAIN=你的店.duckdns.org JWT_SECRET=改一个长密码 docker compose up -d
```

5. 等两分钟，手机开 `https://你的店.duckdns.org/m`。Caddy 自动申请 HTTPS 证书。
6. 建示范数据或正式开店：`docker compose exec server node ../db/scripts/bootstrap-admin.mjs 你的邮箱 123456`，然后用超管登录网页端走开店向导。

注意：Oracle 会回收长期闲置的免费机器（CPU 几乎为 0 连续 7 天），系统有定时任务在跑一般不会被判闲置。

## 不推荐的免费方案

- Render、Railway、Fly 的免费层要么到期要么会休眠，数据库 30 到 90 天后删除，不适合存库存账本。
- Supabase、Neon 的免费 Postgres 不允许我们建专用数据库账号和行级安全角色，要改代码。
- 家里路由器开端口映射：没有 https，手机摄像头不能用，也不安全。
