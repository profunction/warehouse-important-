# 第八部分：风险和对策

## 最要紧的五个

| 排名 | 风险 | 对策 |
|---|---|---|
| 1 | 老年员工不用，回到纸和脑子 | 每屏先给真实老年员工试，不通过不开发。试点陪店两周 |
| 2 | 老板成瓶颈 | 代理、门槛、Telegram 一键批、超时提醒 |
| 3 | 期初数据脏 | 开店前全盘点当期初，导入只走模板预览审批 |
| 4 | Pandal 对接不成或不稳 | 第三阶段前拿文档，两条路，对接层独立 |
| 5 | 电子发票不合规 | 沙盒全流程 + 会计师签字才切生产，重试队列，月结检查清单 |

| 退货作废滥用 | 中 | 高 | 扫原收据经理批。作废老板批。日报列笔数金额 |
| 三方匹配积压 | 中 | 中 | 3 天工单。应付到期报表 |
