# 第五部分：屏幕清单

## 四个屏幕模板

| 模板 | 样子 | 用在哪里 |
|---|---|---|
| T1 首页 | 顶部站点名、我的名字、在线离线标志。中间最多 4 个大按钮（图标、颜色、一行字）。底部语言切换、机器人、登出 | 每个角色首页 |
| T2 清单 | 一列大卡片：照片、标题、说明、状态颜色。点一张进入任务 | 待收 PO、待盘货位、工单、审批 |
| T3 扫描 | 上半屏摄像头取景框，下半屏大字"请扫货位"或"请扫产品"，扫到显示照片名称自动进下一步。"打字输入"小按钮备用 | 所有扫码步骤 |
| T4 输入数量 | 产品照片名称，中间大数字，大数字键盘加"+1 箱""+1 件"快捷键，底部全宽绿色"确认" | 所有输入数量步骤 |

流程：T2 选任务 → T3 扫 → T3 再扫 → T4 输数 → 回 T2。最多三步再确认。

## 反馈规则

| 情况 | 声音 | 颜色 | 文字 |
|---|---|---|---|
| 扫码成功 | 短"叮" | 绿色闪 | 产品名 |
| 任务完成 | "叮叮" | 整屏绿一秒 | "完成！" |
| 扫错或不允许 | 低"嗡" | 整屏红加震动 | 一句话说明 +"知道了" |
| 注意但可继续 | 无 | 黄色横条 | 例如"离线中，稍后上传" |
| 新工单或呼叫 | 铃声加持续震动 | 红色横条 | "顾客在 B 走道需要帮助" |
