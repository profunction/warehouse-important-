# 第一阶段详细规格 第 2 节：四个屏幕模板的线框图和交互细节

适用：安卓手机竖屏 5.5 到 6.7 寸。尺寸 dp，字号 sp。POS 和网页另有布局但沿用颜色、字号比例、声音、反馈规则。

## 全局规则

| 项目 | 规定 | 原因 |
|---|---|---|
| 最小可点面积 | 64 × 64 dp，主按钮高 72 dp | 手指和手抖 |
| 按钮间距 | ≥16 dp | 防误触 |
| 字号 | 正文 22，标题 28，关键数字 56，按钮 24。特大模式 ×1.25 | |
| 字体 | 系统无衬线，数字等宽 | |
| 对比度 | ≥7:1 | 老花和强光 |
| 颜色 | 永远配图标和文字 | 色弱 |
| 手势 | 只用点按。清单滚动唯一例外 | |
| 返回 | 左上"← 返回"大按钮。进行中任务问"放弃这一步？" | |
| 超时 | 10 分钟无操作回首页，未提交保留 | |
| 语言 | 首页底部 中 / BM / EN 立即切换 | |
| 横屏 | 锁定竖屏 | |
| 亮度 | 扫描屏自动最高 | |

## 颜色

| 用途 | 色值 |
|---|---|
| 确认 绿 | #1B8A3A |
| 错误 红 | #C62828 |
| 注意离线 黄 | #F9A825 配黑字 |
| 信息 蓝 | #1565C0 |
| 背景 | #FAFAFA |
| 文字 | #1A1A1A |
| 停用 灰 | #9E9E9E |
| 区颜色 | A 红 B 橙 C 黄 D 绿 E 蓝 F 紫 S 灰，与货位标签同色 |

## 声音

| 事件 | 声音 | 时长 |
|---|---|---|
| 扫码成功 | 1000 Hz 叮 | 100 ms |
| 任务完成 | 上行叮叮 | 300 ms |
| 错误 | 250 Hz 嗡 + 震动 200 ms | 400 ms |
| 警告 | 无声只黄色 | |
| 呼叫 | 铃声震动循环直到按"我去"，60 秒后每 10 秒一次 | |
| 按钮 | 咔哒 + 震动 20 ms | |

静音时仍播放。可调音量，不可关错误音。

```
├────────────────────────────────────┤
│ ┌──────────────┐  ┌──────────────┐ │
│ │     📦       │  │     🛒       │ │ 160×160dp
│ │    收货      │  │    补货      │ │ 图标 64 文字 24
│ │   待收 3     │  │   缺货 12    │ │ 角标红底白字
│ └──────────────┘  └──────────────┘ │
│ ┌──────────────┐  ┌──────────────┐ │
│ │     📋       │  │     🔍       │ │
│ │    盘点      │  │    查询      │ │
│ │   今日 20    │  │              │ │
│ └──────────────┘  └──────────────┘ │
├────────────────────────────────────┤
│ [中] [BM] [EN]      [🎤 问]  [退出] │ 64dp
└────────────────────────────────────┘
```

- 四按钮 2×2，圆角 16，白底 2dp 边框，按下浅绿。边框色固定：收货蓝、补货绿、盘点橙、查询灰。
- 角标零不显示，>99 显示 99+。
- 代理时上方加 64dp 红横条"审批（代老板） 待批 2"。
- 退出弹确认。
- 离线：状态条黄"离线 · 12 笔待上传"，需在线按钮变灰标"需要网络"。

## T2 清单

```
┌────────────────────────────────────┐
│ ← 返回        待收货          [筛]  │ 56dp
├────────────────────────────────────┤
│ 今天 3 张                          │
├────────────────────────────────────┤
│ ┌────────────────────────────────┐ │
│ │ [照片]  F&N 代理               │ │ 112dp
│ │  64dp   PO-2026-0412 · 8 种     │ │ 标题 24 粗 说明 20
│ │         今天到          ● 待收 │ │ 颜色圆点 + 文字
│ └────────────────────────────────┘ │
│ ┌────────────────────────────────┐ │
│ │ ...                            │ │
├────────────────────────────────────┤
│ [        + 无单收货              ] │ 72dp 白底绿字绿框
└────────────────────────────────────┘
```

- 整卡可点。排序系统决定不可改。筛选只给经理以上。
- 空清单：大图标 + "今天没有待收的货" + 绿对勾。
- 状态词固定三语：待收、部分收、已完成、待批、已批、超期。
- 不用下拉刷新，自动刷新，离线显示上次更新时间。

## T3 扫描

```
┌────────────────────────────────────┐
│ ← 返回      收货 · F&N 代理   2/8  │ 56dp
├────────────────────────────────────┤
│   ┌──────────────────────────┐     │ 高 = 屏宽×0.75
│   │   ┌──────────────┐       │     │ 扫描框 240×160
│   │   │              │       │     │ 四角绿 L 标记
│   │   └──────────────┘       │     │
│   └──────────────────────────┘     │
├────────────────────────────────────┤
│         📦  请扫产品条码            │ 32sp 图标 48
│   上一个：可口可乐 325ml  ✓ 24 件   │ 20sp 灰
├────────────────────────────────────┤
│ [ ⌨ 打字输入 ]      [ 🔦 手电 ]     │ 64dp
└────────────────────────────────────┘
```

- 扫到：框闪绿，叮，下半屏换照片 96 + 名称 28 + 关键信息，600 ms 后自动下一步。
- 扫错：整屏红 400 ms + 嗡 + 震动，显示原因 + "知道了" 72dp。
- 同码 2 秒内重扫忽略。
- 指示文字只两种：请扫货位 / 请扫产品。
- 打字输入：全屏数字键盘 72dp。
- 蓝牙枪键盘模式自动接收，与摄像头同时可用。
- 手电离开屏自动关。
- 进度右上 2/8；盘点 7/20 货位。
- 收货拣货允许连续扫同品累加，按输数量进 T4 修正。

## T4 输入数量

```
┌────────────────────────────────────┐
│ ← 返回      收货 · F&N 代理   2/8  │
├────────────────────────────────────┤
│  [照片 96]  可口可乐 325ml          │ 28sp
│             9556001234567           │ 20sp 灰
│             应收 24 件 · 放 S-02    │ 22sp
├────────────────────────────────────┤
│               24                   │ 56sp 等宽右对齐
│                件                  │ 24sp
├────────────────────────────────────┤
│  [ +1 箱 (24) ]   [ +1 件 ]  [ 清 ]│ 64dp
├────────────────────────────────────┤
│   │  1  │  2  │  3  │              │ 键 72dp 高 1/3 宽 32sp
│   │  4  │  5  │  6  │              │
│   │  7  │  8  │  9  │              │
│   │  .  │  0  │  ⌫  │              │ 小数点只公斤出现
├────────────────────────────────────┤
│ [          ✓  确认  24 件          ]│ 80dp 绿底白字 28sp
└────────────────────────────────────┘
```

- 默认值：收货 = 应收，补货 = 后仓全部，上架 = 收货区剩余，盘点 = 空。默认灰色，按键替换。
- 确认按钮含数量。0 时灰，盘点例外。
- 箱码产品顶部"24 件 = 1 箱"，输入永远是件。
- 收货超应收 20% 黄条"比应收多 10 件，确定吗？"不阻止。
- 公斤三位小数。电子秤自动填蓝，手改黑。
- 盘点不显示系统量，确认后不显示差异。
- 到期日：确认后多一屏 12 个月份大按钮 + 年份切换，默认月末可改日。不用日历控件。
- 确认后叮绿闪自动回 T3。

## 叠加层

| 叠加层 | 样子 | 行为 |
|---|---|---|
| 离线横条 | 顶部 48dp 黄"离线 · 12 笔待上传" | 恢复后绿"已同步"2 秒消失 |
| 呼叫横幅 | 顶部 96dp 红"顾客在 B 走道找酱油" + "我去" | 铃声震动。X 忽略 30 秒再响，三次后转下一在班员工 |
| 新审批 | 顶部 64dp 蓝"有 1 项等您审批" | 点进 M1，不响铃 |
| 确认对话 | 居中白卡 280dp，一句话 + 两个 72dp 按钮 | 只用于放弃任务和退出 |
| 加载 | 按钮内转圈变灰 | >3 秒"正在连接……"，>10 秒"网络慢，已保存在手机，稍后上传"并继续 |

## POS 和网页沿用

| 设备 | 沿用 | 不同 |
|---|---|---|
| POS 横屏 | 颜色、声音、字号比例、全宽绿确认、整屏红错误 | 左清单右总额按钮，数字键盘右下。顾客侧屏只显示清单总额无按钮 |
| 网页 | 颜色、状态词、错误写法 | 桌面密度，表格筛选。经理以上用 |
| 大屏竖屏 | 颜色、字号 ×1.5、按钮 96dp | 无登录无返回，只有"重新开始" |
