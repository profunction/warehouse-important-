# 第四部分：角色和权限

## 四条原则

1. 一个人可有多个角色，按站点分配。登录后选站点，首页按该站点角色显示。
2. 权限绑定角色，不绑定个人。换人只需加进同一角色。不允许给个人单独加权限。
3. 审批者不能批自己发起的事。数据库检查 requested_by ≠ approver_id。A 模式一人老板例外，因发起者是系统。
4. 数据范围和动作权限分开。

## 老板代理（授权代批）

定位：老板不在时把审批权暂时交给一个人。有时限、范围、上限，所有记录标明代批。

### 设定步骤

1. 老板在手机或 Telegram：设置 → 我的代理 → 指定代理。
2. 选人：B 模式列经理和会计，A 模式列所有员工。
3. 选范围：订货、盘点差异、退货、手动调整、调拨、供应商付款、Excel 导入、改售价。
4. 选时间：最长 30 天。选金额上限：单笔和每日累计，留空用老板权限。
5. 确认后 Telegram 通知代理人和老板。

### 生效后

- 代理人首页多出红色"审批（代老板）"第五个按钮，到期消失。这是唯一允许超过四个按钮的情况。
- 审批请求同时发老板和代理人，谁先按谁算。老板权力不被剥夺。
- ApprovalRequest 记 approver_id = 代理人，on_behalf_of = 老板，delegation_id。日志、PDF、Telegram 都显示"由 XX 代老板批准"。
- 每晚老板收到代理动作汇总。
- 到期自动失效。老板随时可撤销。

### 代理人不能

| 不能 | 原因 |
|---|---|
| 再指定别人 | 授权不能转手 |
| 修改延长自己的代理 | 只有老板能改 |
| 改门槛、折扣上限、角色权限 | 设定权不是审批权 |
| 批自己发起的请求 | 原规则 |
| 看成本（本身角色看不到） | 代理的是审批权不是数据范围。勾选订货和付款时系统提示老板"此人将看到采购金额"，老板确认才生效 |
| 作废已完成销售、月结锁定、新建用户、设定对接 | 不在可代理清单 |

### 老板失联

- A 模式：超管按合约预留的紧急联系人顺序开 48 小时临时代理，范围只有盘点差异和退货。通知老板和联系人。
- B 模式：老板预设"常备代理人"，审批超 24 小时无人处理自动发给常备代理人并通知老板。

同样机制给经理用：休假时把自己的审批交给另一个经理或老板，范围只能是经理自有权限。
